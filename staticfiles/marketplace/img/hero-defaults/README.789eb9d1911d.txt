Hero Default Images
====================

These are the static fallback images for the 5 fixed hero carousel slots.
They are used when no active DB override Promotion exists for a slot.

Recommended dimensions: 800x400px (JPG or PNG)

Slot filenames (fixed — do not rename):
  campus-essentials.jpg    — Slot 1: General campus life / catch-all category
  tech-electronics.jpg     — Slot 2: Phones, laptops, gadgets
  fashion-accessories.jpg  — Slot 3: Clothing, shoes, accessories
  food-beverages.jpg       — Slot 4: Snacks, drinks, meals
  deals-marketplace.jpg    — Slot 5: Discounts, flash sales, promos

To replace: just overwrite the file with your own 800x400 image.
The site will pick up the new image on the next page load (clear browser cache if needed).
